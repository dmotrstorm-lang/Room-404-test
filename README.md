# ROOM 404 — The Unremembered

Самостоятельная браузерная point-and-click игра в классическом сюрреалистичном стиле: рисованные интерьеры, исследование предметов, журнал улик, инвентарь, шесть глав и три финала.

## Запуск

Откройте `index.html` в современном браузере. Для публикации на GitHub Pages загрузите `index.html`, `style.css` и `game.js` в корень репозитория и включите Pages для нужной ветки.

## Управление

- Нажимайте на предметы в сцене, чтобы осмотреть их.
- Читайте найденные заметки в правой панели или в разделе «Записи».
- Решайте загадку главы через окно осмотра.
- После решения откроется следующая глава.
- Прогресс автоматически сохраняется в LocalStorage этого браузера.

## Содержание

1. Чужой порог
2. Комната для двоих
3. Отель «Последний гость»
4. Музей забытых лиц
5. Архив под лестницей
6. Комната без окон

В финале доступны три разные концовки. Проект не использует сторонние JavaScript-библиотеки и не требует сборки.
